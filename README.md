# United Royale Corporation — Design Concepts

Next.js redesign concepts for [United Royale Corporation](https://unitedroyalecorp.net/).

## Designs

| Route | Name | Direction |
| --- | --- | --- |
| `/` | Picker | Compare both concepts |
| `/design-a` | **Soft Path** | Calm light UI, Outfit + Plus Jakarta Sans, dual business/job pathways |
| `/design-b` | **Bright Signal** | Fresh Gen Z/Alpha energy, Sora + Manrope, scan-friendly bento services |

Both keep a **light** overall look and pull **logo colors** (royal blue, gold, maroon accents) into the navigation and CTAs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Covered feedback themes

- Stronger homepage hierarchy and value proposition
- Grouped services with icons + client benefits
- Measurable achievements / stats
- Testimonials and clearer About (mission, vision, CARE values)
- Persistent CTAs (consultation, proposal, apply, contact)
- Careers path written for non-technical applicants
- Insights / news teaser section
- Mobile-friendly responsive layouts
